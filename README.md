Entry for make.fun's **A Day of One-Line Pitches** bounty
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

`main.py` writes one original one-sentence pitch to `/output/entry.txt`:

> Tell make.fun the app idea you've been sitting on, in your own words, and an AI agent builds a working first version for you — no code, no jargon, just your idea turned into something you can actually click.

207 characters — one sentence, written for a friend who has never coded:
the idea stays theirs, the building is the agent's, and the first thing
they get back is something real they can click.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (validated: 1–240 characters, UTF-8, not
whitespace-only).
